## 🎯 About Me

I'm an engineering student at **École Hassania des Travaux Publics (EHTP)** in Casablanca, working at the intersection of **Geographic Information Systems, Data Science, and Software Engineering**. I like building applications that turn raw, messy data — spatial or tabular — into something usable: mapped, modeled, or served through a clean interface.

On the engineering side, I build full-stack web applications with **Spring Boot** and **ASP.NET Core**, designing RESTful APIs and relational data models rather than just gluing frontend to backend. On the data side, I work with **Scikit-learn, TensorFlow, and PyTorch** for machine learning pipelines, and with **PostGIS, ArcGIS Pro, and QGIS** for spatial analysis — a combination that isn't common and that I'm actively trying to deepen.

**Open to:**
- 🎓 A 2-month **PFA internship** starting **July 2026**
- 🤝 Collaborations on GIS + Data Science projects
- 💬 Conversations about spatial data pipelines, ML, or full-stack architecture
